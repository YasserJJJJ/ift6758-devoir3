# Données du devoir

Ces fichiers proviennent du ZIP original du devoir 3.

- `reddit-counts.json.gz` : décomptes quotidiens de commentaires Reddit; Pandas lit directement le fichier compressé.
- `standard_oct22frl_xml.zip` : liste FIDE d’octobre 2022; `chess_rating.parse_xml()` extrait automatiquement le XML dans ce dossier.

Le fichier XML décompressé est ignoré par Git. Les données ne font pas partie des fichiers à remettre sur Gradescope.
